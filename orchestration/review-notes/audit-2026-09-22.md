# Whole-codebase adversarial audit, 2026-09-22

Run by a separate Opus 5.5 agent against a frozen snapshot at `aa49d72`
(T01 through T26 complete). The baseline was green: every test passed and all
51 gold entries verified. None of these defects is caught by the current suites.

The orchestrator independently reproduced every finding marked **verified**
below on the post-T27 binary, with its own fixtures. Resolver code was unchanged
between the audit snapshot and T27.

## Critical: wrong `exact` bindings

1. **Top-level closure loses its namespace and imports.** `uses.rs:1009`,
   `parent_scope_key` returns `None` for any `top:N` key, so a file-level
   closure cannot see the file's namespace or `use` imports and resolves in the
   global namespace. `namespace App; $f = function(){ launch(); new Thing(); };`
   with global `launch` and `Thing` elsewhere binds both `exact` to the globals.
   **Verified.**
2. **Multi-namespace file resolves every block against the first.**
   `resolve/mod.rs:352` takes the first `Module` in the declares list; imports
   and top-level functions all land in `top:file`. `namespace First; ... function
   build(){}` then `namespace Second; function caller(){ build(); new Widget(); }`
   binds both `exact` to `First\...`. A `use` inside one braced block also leaks
   into another. **Verified.**
3. **Global `namespace { }` block inherits the previous block's name.**
   `php/mod.rs:225` records a namespace only when it has a name. `namespace A {
   class X {} } namespace { class Y {} function helper(){} }` gives symbol IDs
   `a.php#A\Y` and `a.php#A\helper` instead of `a.php#Y` and `a.php#helper`.
   Wrong symbol identity that looks right. **Verified.**
4. **Fully qualified function call binds to a class.** `rules/imports.rs:65`
   calls `unique_resolved` with no kind filter. `class Maker {} \Maker();` binds
   the call `exact` to the class. **Verified.**

## High: wrong `scoped` bindings

5. **Member lookup ignores the use kind.** `resolve/mod.rs:212`, `:240`. A
   method call can bind to a property and a property read to a method.
   `class C { public $items; public function run(){ $this->items(); } }` binds
   the call to `C::$items` even though no method `items` exists. **Verified.**
6. **Typed-parameter receivers skip every rebinding check added for `new`
   receivers in T21/T21a/T21b.** `rules/receivers.rs:39`; `uses.rs:726`.
   `function f(A $x){ takes_ref($x); $x->m(); }` binds `A::m`. The audit also
   reports reference aliases, `extract`, `preg_match` into `$x`, and
   reassignment later in a loop. **Verified** for the by-reference case.
7. **Union type binds to its last member.** `uses.rs:1083`, `first_named_type`
   pops a stack. `function g(A|B $x){ $x->m(); }` binds `B::m`. A union should
   stay unresolved. Also feeds property types. **Verified.**
8. **`new`-receiver rebinding forms still missed.** Reference alias `$y = &$x;
   $y = new B();` (**verified**); a constructor by-reference argument
   `new Holder($x)` with `__construct(&$v)`; a file-scope global rebound by a
   called function through `global $x`.

## Low: wrong bindings on rarer input

9. **An attribute containing the word "function" breaks by-reference
   parameter parsing.** `rules/new_expr.rs:280` anchors on the first
   `"function"` in the signature text.
10. **Unicode case folding where PHP folds only ASCII.** `resolve/mod.rs:116`,
    `:144`, and `to_lowercase` generally. `class Ä {}` with `new ä()` binds
    `exact`; PHP treats them as different classes.

## Medium: silent misses reported as complete

11. **Anonymous class bodies are never walked.** `uses.rs:602`,
    `visit_object_creation` visits only the name and arguments.
12. **A use's lookup name is its whole lowercased spelling, not the normalized
    short name.** `refresh.rs:840`. An unresolved `new Sub\Missing\Foo()` is
    stored as `sub\missing\foo` and never name-matches `Foo`; candidate mode
    returns total 0. A bare constant `LIMIT` is stored lowercased while the
    declaration is case-sensitive. **Verified.**
13. **Class references miss static calls, constant access and `::class`.**
    `uses.rs:508`, `visit_class_constant`.
14. **TypeScript files count as indexed with no extraction, even when invalid.**
    `rivet-parser/src/lib.rs:38`. An invalid `a.ts` reports `files_indexed: 1`,
    `complete: true`, no `parse_error`.

## Contract conformance

15. **Error objects omit `index` after a snapshot was acquired.** OUTPUT-CONTRACT
    "Errors": index-dependent errors include `index` when a compatible snapshot
    was acquired. `symbol nosuch --json` has no `index` key. **Verified.**
16. **`updated` does not count files whose facts were regenerated.**
    `rivet-store/src/lib.rs:616`. After a fingerprint change, nine files are
    reparsed but the output reports `updated: 0`.
17. **Non-UTF-8 path diagnostic uses the absolute lossy path.** `walk.rs:175`.
    Code-read only; APFS refuses such filenames. The test at `walk.rs:480` only
    checks `contains("bad-")`, so it passes.

## Unverified suspicions

- **Reads are not snapshot-consistent.** Each `Store` read opens its own
  transaction, and refresh reads and parses outside the writer transaction,
  contradicting ARCHITECTURE. The race is not reproduced. Belongs to T31.
- **`--no-refresh` accepts a cache built by an older extractor.** It checks only
  `index_format_version`, not `extractor_fingerprint`.
- **A namespaced call may fall back to a global function when the namespaced
  declaration's file failed to parse**, binding `exact` under partial coverage.

## Coverage the audit reported as thin

Skimmed: `signature.rs`, `config.rs` internals, `root.rs`, `id.rs` ordinals,
`context.rs`. Not covered: symlink, FIFO and permission-denied walks; SQLite
rollback on a crash mid-publish.
