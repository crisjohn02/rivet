## The task format, fixed by the orchestrator

Each task is a directory `/Users/cris/rivet-corpus/gold/pilot/<task-id>/` holding:
- `task.toml` with `id`, `project = "timesheet"`, `category` (one of `locate`, `trace`, `callers`, `tests`, `dependencies`), `check` (one of `exact_symbol`, `set_f1`, `accepted_path`), `f1_threshold` for `set_f1`, and `[limits]` with `max_budget_usd`, `max_turns` and `wall_seconds`.
- `prompt.md`, the task text both arms receive identically, ending with an instruction to give the answer as a final fenced `json` code block in the stated shape.
- `gold.json`, the expected answer.
The check types:
- `exact_symbol` is one file and one symbol.
- `set_f1` is a list of file-and-symbol items, passing at F1 of at least `f1_threshold`.
- `accepted_path` is an ordered call path, passing if it equals any accepted path.
Use opaque task IDs such as `p1` to `p6`; they appear in the public report.
