T07 — Bounded regular-file reads, content hashing, and skip classification. No database, no parsing.

Put this in `crates/rivet-core/src/source.rs`. Add `blake3` (pinned `=x.y.z`) to `rivet-core`. No other new dependency.

Requirements:
1. `read_source(root: &Path, entry: &FileEntry, max_bytes: u64) -> SourceRead` where `SourceRead` is an enum: `Ok { bytes: Vec<u8>, hash: String }` or `Skipped { reason: SkipReason }` or `Failed(io error)`. `SkipReason` enum: `Size`, `Binary`, `Encoding`, `Symlink`, `NotRegular`. Hash format is exactly `blake3:` followed by 64 lowercase hex digits.
2. Safety rules from spec §27: open with `std::fs::File::open` on the joined path, then `fstat` the open handle (`metadata()` on the File) and reject if it is not a regular file (covers FIFOs, devices, directories) or if `symlink_metadata` on the path says it is a symlink (check the path BEFORE opening; on Unix additionally verify after open that the opened file's `(dev, ino)` matches the pre-open `symlink_metadata`, to catch a swap between stat and open; return `NotRegular` on mismatch). Read at most `max_bytes + 1` bytes with a bounded reader; if more than `max_bytes` are available, return `Skipped { Size }` without reading the rest. Never read a whole file to decide it is too large.
3. Classification order after a successful bounded read: `Size` if over limit; `Binary` if the first 8 KiB contain a NUL byte; `Encoding` if `std::str::from_utf8` fails on the full content; otherwise `Ok`. Store bytes exactly as read: no CRLF normalization, no BOM stripping (a UTF-8 BOM is valid UTF-8 and stays).
4. `pub fn content_hash(bytes: &[u8]) -> String` as the single hashing function; test that it produces the documented `blake3:` prefix and 64 hex chars, and that known input `b""` gives the well-known BLAKE3 empty hash `af1349b9f5f9a1a6a0404dea36dcc9499bcb25c9adc112b7cc9a93cae41f3262`.
5. Tests (temp dirs under `std::env::temp_dir()`): regular UTF-8 file returns Ok with matching hash; file exactly at `max_bytes` is Ok and one byte over is `Size`; a file with a NUL in the first bytes is `Binary`; invalid UTF-8 (e.g. `0xff 0xfe`) is `Encoding`; a symlink to a valid file is `Skipped(Symlink)` (`#[cfg(unix)]`); a FIFO is `Skipped(NotRegular)` without hanging (`#[cfg(unix)]`, create via `mkfifo` command, skip test if unavailable, and open must not block: open FIFOs with `O_NONBLOCK` via `std::os::unix::fs::OpenOptionsExt::custom_flags(libc-free constant 0o4000)` or detect via `symlink_metadata().file_type()` BEFORE open and return `NotRegular` without opening at all; prefer the pre-open check); CRLF and BOM bytes are preserved byte-for-byte.
