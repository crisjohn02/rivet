T21b — Suppress `new`-receiver bindings when a scope contains a rebinding the walker cannot analyse.

T21a closed every rebinding form that appears syntactically as a binding target. It disclosed, and I confirmed against the binary, that these still produce a wrong `scoped` binding:

1. A callee-declared by-reference parameter: `function takesRef(&$x)` called as `takesRef($s)`. The call site carries no `&`.
2. A by-reference builtin: `preg_match('/x/', $subject, $s)`, and likewise `sort`, `array_push`, `parse_str`, `array_shift`, `array_unshift`, `array_splice`, `settype`, `similar_text`, `str_replace` with a count argument.
3. A dynamic variable write: `$$name = ...` and `${$expr} = ...`.
4. `$GLOBALS['s'] = ...`.
5. `extract($arr)`, which can create or overwrite any local.
6. `eval(...)`, which can do anything.

Each of these is an honesty violation: the binding claims a class the variable may not hold.

Requirements:

1. Prefer suppression over analysis. For 3, 4, 5 and 6 the walker cannot know which variables are affected, so the correct response is to record no `new`-receiver binding anywhere in that scope. Implement this as a per-scope "unanalysable" flag that the rule consults, rather than by inventing per-variable facts you cannot justify. Say exactly how you represented it and how it reaches the resolver.

2. Case 1 is resolvable and should be resolved, not blanket-suppressed. When the callee is an indexed function or method whose declaration is available, read its parameter list: if the matching parameter is by-reference, treat the argument as a rebinding of that variable; if it is not, the call does not rebind and the binding may stand. When the callee cannot be resolved to exactly one indexed declaration, suppress. State plainly which lookup you used and what happens for a method call on an unknown receiver.

3. Case 2 needs a table, since builtins have no indexed declaration. Add a small, documented list of PHP builtins with by-reference parameters, naming the parameter position for each. An unknown global function that is not indexed must suppress rather than be assumed safe. Say where you put the table and what governs adding to it.

4. The default on anything unrecognised is no binding. Never guess, never `exact`.

5. Do not regress T21a. Every form in the T21a review table must stay unbound, and the safe single-assignment case must still bind `scoped`. The authored fixture must stay at 13 bindings; if it changes, stop and report rather than adjusting the expected number.
