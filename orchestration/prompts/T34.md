T34 — Add compact human output and help for the implemented commands. JSON output is normative and must not change at all.

Requirements:

1. Human output follows the spec's shapes. `symbol` follows §14: name, kind, location, signature, then `calls:` and `called by:` lists. `refs` follows §15: a header such as `3 references  (2 scoped, 1 name_match)`, then one line per reference with `file:line`, the containing symbol, and the kind. `context` follows §16.1: a `── file:start-end  name  [reason, form]` header per segment, followed by that segment's SOURCE, then an `estimated_tokens: X / Y  (tokenizer: utf8-bytes-v1; budget_scope: source)` line. `index` follows §13's possible output. `init` and `snippet` keep what T33a and T33b built.
2. A carried-forward fix. T30's plain `context` output deliberately printed no source text, as a placeholder until this task. Spec §16.1's human form prints each segment's source under its header, and source is the whole point of `context`. Print it.
3. Nothing the JSON conveys may be lost in the human form, per the T34 row: "Resolution marks, pagination, coverage, and context forms remain visible."
   - Resolution: every `name_match` result is marked with a trailing `?`, per §11.3 "Human output marks `name_match` results with `?`", in `refs` and in `symbol`'s call lists. Decide whether `scoped` is distinguished from `exact` too, and state it.
   - Pagination: when a list is truncated, say so and give the next offset, for example `showing 1-50 of 120; next: --offset 50`, for refs, both symbol call lists, and ambiguity candidates.
   - Coverage: whenever coverage is incomplete, show a short line naming the skipped counts and the diagnostic count, so an empty or short result is never mistaken for a complete one. The snippet itself tells agents to "check coverage/skipped files ... before relying on an empty result".
   - Context: each segment's reason and form, the omission counts when any are non-zero, and a line when `candidate_limit_reached` is true.
4. Errors in human mode print a short message and the hint on stderr with the documented exit code, and nothing on stdout. Keep the codes exactly as today.
5.
