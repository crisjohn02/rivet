Requirements:
1. `walk_eligible(root: &Path, config: &Config) -> Result<Vec<FileEntry>>` where `FileEntry { rel_path: String (repo-relative, '/' separators, filesystem spelling preserved), size: u64, mtime_ns: i128 or u128 }`. Only regular files. Deterministic output: sorted by `rel_path` bytes.

Ignore rules, exactly per spec §26: always exclude `.git/` and `.rivet/`; default excludes `node_modules/`, `vendor/`, `dist/`, `build/`, `target/`, `coverage/` (as directory names at any depth); plus `config.index.exclude` globs (gitignore-style, relative to root).
