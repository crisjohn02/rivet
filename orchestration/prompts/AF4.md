AF4 — Close the silent misses. Each of these makes `refs` return an incomplete list while reporting it as complete, which is quieter than a wrong binding but still dishonest.

The defects:

1. Finding 11. Anonymous class bodies are never walked. `visit_object_creation` in `uses.rs` visits the class name and arguments but never the body, so `new class { function run(Dep $d){ launch(); new Dep(); } }` records no `launch` or `Dep` use and `refs` returns total 0.
2. Finding 12. A use's stored lookup name is its whole lowercased spelling, not its normalized short name. An unresolved `new Sub\Missing\Foo()` is stored as `sub\missing\foo`, so it never name-matches a declaration `Foo` and candidate mode misses it. A bare constant `LIMIT` is stored lowercased while the constant declaration is case-sensitive, so it never matches either.
3. The first "Already known" item, which is the same function's problem. A PHP property declaration keeps its leading `$` in its stored lookup name while a member use drops it, so an unresolved property use never name-matches its declaration.
4. Finding 13. A class named explicitly in a static call, a class-constant access, or `::class` is never recorded as a reference to that class. `refs 'App\Foo'` does not list `Foo::make()`, `Foo::BAR` or `Foo::class`.
5. Carried from the AF2 review. An `instanceof` operand is recorded as an unclassified use, and since AF2 correctly made unclassified fully qualified uses bind only constants, `$x instanceof \App\I` no longer binds the interface. Record the operand as a type use so it binds as a class reference again.

Read this trap before fixing item 1. Inside an anonymous class body, `$this`, `self` and `static` refer to the ANONYMOUS class. The existing receiver rules find the nearest NAMED enclosing class, which would be the class that CONTAINS the `new class` expression. Walking the body naively would therefore bind `$this->run()` inside the anonymous class to a same-name method on the outer class, turning a silent miss into a wrong binding, which is strictly worse. Uses inside an anonymous class body must be recorded, per spec §10.1 with the nearest named container, but `$this`, `self` and `static` there must bind nothing. Assert this directly with an outer class that declares a same-name method.
