T05 — Root discovery and config validation. No traversal, no hashing, no database, no instruction-file writes.

Put this in `rivet-core` unless it needs filesystem walking of the whole tree (it does not). Suggested modules: `crates/rivet-core/src/root.rs`, `crates/rivet-core/src/config.rs`.

Requirements:
1. `discover_root(start: &Path) -> Result<RootInfo>`: walk upward from `start` (canonicalized) and select the NEAREST ancestor (including `start` itself) that contains a `.rivet/` directory or a `.git` entry that is either a directory or a regular file (worktrees use a `.git` file). Stop at the first such boundary. Return `RootInfo { root: PathBuf, has_rivet_dir: bool, has_git: bool }`. If nothing is found, return an error variant that the CLI will later map to exit 3, with a message telling the user to run `rivet init`. Never follow a symlinked `.rivet` directory: if `.rivet` is a symlink, return an error naming it (spec §27).
2. `Config` struct mirroring spec §22 exactly: `[index] respect_gitignore (bool, default true)`, `exclude (Vec<String>, default the four spec globs)`, `max_file_size_kb (u64, default 1024)`, `freshness ("content" | "metadata", default content)`; `[languages] enabled (Vec<String>, default ["php","typescript"])`; `[context] default_token_budget (u32, default 4000)`, `include_tests (bool, default true)`, `test_globs (Vec<String>, default per spec)`, `max_depth (u8, default 2, allowed 1 or 2)`, `collapse ("auto"|"always"|"never", default auto)`; `[output] default_limit (u32, default 50, allowed 1..=1000)`.
3. `Config::load(root) -> Result<Config>`: if `.rivet/config.toml` is absent, return defaults. If present, parse with `toml` using `serde` with `#[serde(deny_unknown_fields)]` on every table so unknown keys are errors, and validate ranges (max_depth, default_limit, freshness/collapse enums, max_file_size_kb > 0, non-empty enabled list). Errors must name the key and the offending value. Also provide `Config::default_toml() -> String` producing the exact spec §22 text with default values (used by `init` later) and a test that `default_toml()` parses back to `Config::default()`.
4. `Config::fingerprint() -> String`: a stable hash-free canonical serialization (sorted keys, normalized values) of only the fields that affect indexing (`[index]`, `[languages]`), used later for cache invalidation. Test that reordering keys in the TOML yields the same fingerprint and that changing `exclude` changes it.
5. Add dependencies to `rivet-core` only: `serde` (derive), `toml`. Pin them with `=x.y.z` in `[workspace.dependencies]` after checking `cargo search`. No other new dependencies.
6. Tests: use `tempfile`-free tests by creating temp dirs under `std::env::temp_dir()` with a unique suffix and cleaning up. Cover: nested dirs where an inner `.rivet/` beats an outer `.git`; an inner `.git` FILE (worktree) beats an outer `.git` directory; starting inside a subdirectory resolves to the boundary above it; no boundary returns the init hint error; symlinked `.rivet` is rejected; unknown config key is rejected with the key name in the message; `max_depth = 3` rejected; `default_limit = 0` rejected; `freshness = "fast"` rejected; missing config yields defaults.
