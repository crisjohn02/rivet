## Decisions (orchestrator, final; apply them and record them in the docs)

T41 left these questions open. Resolve the gold's T42 `[[undecided]]` entries into
`[[declaration]]` or `[[not_a_declaration]]` accordingly.

1. **Type aliases are symbols** of a new kind, `type_alias`.
   - This is an additive contract change. Add it to `SymbolKind` with `as_str` `type_alias`, to
     the OUTPUT-CONTRACT kind list, to the spec wherever kinds are enumerated, and to the
     ADDING-A-LANGUAGE TypeScript column.
   - Lookup follows TypeScript's case-sensitive rule.
   - A generic type alias is one symbol.
2. **Generic type parameters are not symbols.** The generic class, interface, function or alias is
   one ordinary symbol.
3. **Function-local declarations are not symbols:** local consts, functions and classes inside a
   function body. This follows PHP, where locals are never symbols. Uses inside them attach to
   the enclosing named symbol (T43).
4. **Getters and setters are each a `method` symbol.**
   - A pair sharing a name gets the spec §10 ordinals in source order.
   - The signature summary shows `get`/`set`.
5. **Overload signatures fold into one `function` or `method` symbol.**
   - When an implementation exists in the same scope, the symbol is the implementation's
     declaration: its span and its signature.
   - When none exists, as in `.d.ts` files, ambient declarations and interface method overloads,
     the symbol is the **first** signature.
   - The other signatures are not symbols.
   - Record the folded count in no output. This rule keeps IDs stable.
6. **String-named ambient modules** (`declare module "x" {}`) are not symbols, and neither are
   their members. Identifier-named ambient declarations are named as in a `.ts` file.
7. **Spans** include `export`, `export default` and `declare`, as T41's gold decided. Class and
   interface member spans follow the grammar and exclude a trailing `;`.
8. **Following PHP:**
   - enum members are `const`;
   - interface members are `method` or `property`;
   - fields and parameter properties are `property`;
   - the constructor is `Class.constructor`;
   - `#private` names keep `#`, escaped per §10;
   - declaration merging (`interface X` twice, namespace merging) gets ordinals.

## Build

- **Adapter.** Add a `typescript` adapter under `crates/rivet-languages/src/typescript/`, behind
  `lang-typescript`, for both grammar variants.
  - It extracts named definitions with kind, qualified name, canonical ID, span, name span,
    parent containment, signature summary, and doc comment where the PHP adapter records one
    (JSDoc `/** */` directly above).
  - Qualified names use lexical nesting with `.`. The file path distinguishes modules, exactly as
    ADDING-A-LANGUAGE says.
  - Use reviewed `.scm` queries where they suffice, and a documented walk where they do not.
- **Anonymous containers.** An anonymous default-exported class or function creates **no**
  symbol. Its named members, if any, follow whatever the PHP anonymous-class rule does; say which
  rule you apply. Mind the grammar quirk the fixture README documents.
- **Parse policy.** A file with `ERROR` or missing nodes yields no facts and one `parse_error`, as
  for PHP. Apply the same resource limits.
- **The extractor switch stays `false` for TypeScript.**
  - T43 adds uses and imports, then flips it. Indexing TypeScript files with definitions but no
    uses would make `refs` return misleading empty results.
  - So the CLI's output must stay byte-identical to HEAD, and the existing no-change test must
    keep passing.
- **Verification without the CLI.** Verify T42 gold against the extractor directly: extend
  `typescript_gold.rs` so it runs the adapter on every fixture file and compares every T42 entry,
  including `not_a_declaration` entries.
  - Mark T42 done in the gold's done list.
  - Make `check_gold.py` report truthfully which harness verified the TypeScript entries. For
    example, `typescript T42: 93 entries verified by crates/rivet-languages/tests/typescript_gold.rs`.
    Either invoke that test, or report that `cargo test` owns them; choose one and document it.
  - It must never claim a verification it did not run.
- **Determinism.** The extractor output for the fixture is byte-identical across runs and
  independent of file order.
